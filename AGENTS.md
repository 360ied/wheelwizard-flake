# AGENTS.md

Guidelines and operational instructions for AI coding agents working in this repository.

## Project Overview

This repository provides a standalone Nix Flake packaging [WheelWizard](https://github.com/TeamWheelWizard/WheelWizard), the launcher and mod manager for Retro Rewind (Mario Kart Wii).
It is based on the upstream Nixpkgs packaging effort (originally [NixOS/nixpkgs#557011](https://github.com/NixOS/nixpkgs/pull/557011)).

## Repository Structure

- `flake.nix`: Main flake entry point defining packages, apps, overlays, and devShells.
- `package.nix`: Nix derivation for WheelWizard using `buildDotnetModule` (.NET 10).
- `deps.json`: NuGet dependency lockfile generated by `nuget-to-json`.
- `flake.lock`: Nix flake lockfile.
- `README.md`: User documentation.
- `.agents/skills/update-wheelwizard/`: Workspace skill containing automated script and runbook for bumping releases.

## Common Commands

### Building & Checking
- **Build default package**:
  ```bash
  nix build
  ```
- **Run flake checks**:
  ```bash
  nix flake check
  ```
- **Inspect flake outputs**:
  ```bash
  nix flake show
  ```
- **Run application directly**:
  ```bash
  nix run
  ```

### Updating WheelWizard

To check for and apply upstream updates, activate or follow the [`update-wheelwizard`](.agents/skills/update-wheelwizard/SKILL.md) workspace skill:
```bash
./.agents/skills/update-wheelwizard/scripts/update.sh
```

## Agent Guidelines & Conventions

- **Targeting**: Only maintain the latest upstream version unless explicitly requested otherwise.
- **Git Staging**: Nix flakes only see files tracked by Git. Always stage new or modified files (`git add`) before running flake commands.
- **Verification**: Always run `nix flake check` and ensure clean evaluation before concluding tasks.
- **Formatting**: Keep Nix expressions clean, formatted, and idiomatically aligned with Nixpkgs conventions.
